# Awesome Status Pages [![Awesome](https://cdn.rawgit.com/sindresorhus/awesome/d7305f38d29fed78fa85652e3a63e154dd8e8829/media/badge.svg)](https://github.com/sindresorhus/awesome) [![Update stars](https://github.com/mhb8898/awesome-status-pages/actions/workflows/update-stars.yml/badge.svg)](https://github.com/mhb8898/awesome-status-pages/actions/workflows/update-stars.yml)

Awesome list of open source status page software, hosted status page services, and public status pages of major internet companies.

> Based on **[ivbeg/awesome-status-pages](https://github.com/ivbeg/awesome-status-pages)** by [Ivan Begtin](https://github.com/ivbeg) — all credit for the original list goes to him and its contributors. This repo extends it with star rankings and automatic updates.

**What's different here:**

- ⭐ **Open source projects are ranked by GitHub stars**, so the most popular and battle-tested tools come first.
- 🔄 **Star counts refresh automatically every week** via [GitHub Actions](.github/workflows/update-stars.yml).
- ➕ **Pending community contributions merged** — reviewed entries from open pull requests on the [original list](https://github.com/ivbeg/awesome-status-pages) are included.

If this list helps you, please give it a ⭐ — it helps others find it.
